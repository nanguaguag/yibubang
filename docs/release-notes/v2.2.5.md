相比 v2.2.4，本版带来了全新的医考帮点赞与个人历史评论归纳及云同步功能、题目评论区四维排序聚合看板，完成了医考帮官方双向同步全链路白盒加固，并精确对齐了卡片池各板块筛选范围与列表数量。

## 医考帮官方双向同步链路全线加固

- **离线同步队列重构**：修复入队原子性、队头死锁与 Token 失效保护，统一做题、斩题、重做与笔记队列，支持退避重试与异常隔离。
- **做题记录与拉取策略优化**：修复主观题/填空题自评发往医考帮接口的问题，主观题自评严格保留在本地；拉取做题记录时 100% 完整落入本地库（含 Question、Activities、斩题状态与答案）。
- **笔记与附图双向同步**：完善正文与图片协同上传/拉取，杜绝并发覆盖冲突与孤儿图片。

## 医考帮点赞与评论归纳及云同步（Issue #24）

- **我的点赞与我的评论**：新增归纳管理页面，对接官方接口读取用户点赞记录与个人历史评论，与笔记收藏同等规格管理并支持一键取消点赞。
- **已做题库后台扫描同步**：支持扫描已做题库题目并批量同步远端点赞与评论数据，提供预计时间弹窗确认、后台静默运行与实时胶囊进度条，支持随时取消并具备全局并发互斥保护。

## 评论区四维排序看板

- **独立四维聚合页面**：从题目评论区可进入独立排序看板，支持「最多点赞」、「最高热度」、「最多回复」、「最新发布」四大 Tab，全面适配官方接口。

## 卡片池与交互导航优化

- **卡片池数量精确对齐**：卡片池中「错题攻克」、「星标收藏」、「速记笔记」、「自制闪卡」、「熟练斩题」点击进入后精确对齐所选卡包/题库范围数量，并支持一键清除筛选切换全局视图。
- **闪卡页面返回层级修复**：修复在闪卡详情页编辑并保存闪卡时直接返回卡包管理页面的问题，修正为平滑返回闪卡详情。
- **社区交流**：设置-关于医不帮页面加入官方 Telegram 交流群链接（t.me/yibubang）。

## 自动化测试与质量保障

- **测试门禁**：通过全量静态类型分析与核心测试用例验证。

## ⚠️ 重要：Android 官方统一签名与升级指引

- **永久统一官方签名**：自本版（v2.2.5）起，Android 发布包已全面采用永久固定的官方 Release 签名密钥，彻底解决此前 CI 随机生成 Debug 证书导致覆盖安装报签名冲突的问题。未来所有版本均支持直接点击无缝覆盖升级。
- **历史版本升级数据保护指引**：
  由于历史旧版（v2.2.4、v2.2.3 等）使用的是随机调试签名，与正式签名无法直接覆盖安装。请 Android 用户升级时按如下步骤操作以保护数据：
  1. 打开旧版，在**「设置」->「数据与备份」**中点击**「导出全部数据」**将题库记录与笔记导出备份；
  2. 卸载旧版应用；
  3. 安装本次正式签名的 `v2.2.5` 安装包；
  4. 进入新版「设置」->「数据与备份」，点击「恢复数据」导入备份即可无缝恢复；
  5. 之后的所有后续新版本均可直接覆盖安装，无需再卸载。
