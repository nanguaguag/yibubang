相比 v2.0.5，本版带来完整的题库订阅、制作与导出流程，同时改进刷题、同步和桌面端体验。

## 题库管理与订阅

- 支持订阅链接和本地 SQLite / ZIP 文件导入。订阅地址可修改、自动去重，保存配置时无需重新下载题库。
- 分开“检查更新”与“下载更新”，复用已校验的下载包，减少重复传输；兼容 Gitee、Cloudflare R2 等文件直链，并在检查失败时显示具体原因。
- 更新可选择合并或替换：合并保留本地补充题目，并采用远端同题的新内容；两种方式都保留个人作答、收藏与笔记。
- 在设置中调整自动检查间隔，并单独选择是否自动安装更新。自动检查在应用运行期间执行，本地有补充时先确认再更新。
- 详情页展示学科编号、课程 / 章节 / 题目总数、覆盖课程、文件大小与更新记录。支持导出完整题库为 SQLite / ZIP，也可删除本地题库并保留个人记录。

## 自建题库与内容同步

- 登录医考帮后选择学科，生成独立题库；支持父子联动勾选与半选，自建题库更新时自动递增版本。
- 创建前提示会员权限与使用风险；遇到无权限或其他错误，可选择忽略、忽略全部或终止，完成后查看成功与失败明细。
- 课程页集中提供智能同步、做题记录拉取与全量重建，显示阶段和题量进度；拉取记录时保留本地已有答案。
- 大型学科树改为按需加载与局部刷新，显著改善勾选和滚动时的卡顿。

## 刷题与界面体验

- 新增可配置的刷题快捷键，支持冲突处理，并避免在输入框与弹窗中误触。
- 护理等题库的填空、名词解释、简答等主观题支持参考答案核对与自评，完善题型筛选。
- 打磨 Material Design 页面、紧凑状态标签与按钮原位进度，优化笔记、错题和收藏浏览。
- 桌面端采用侧栏导航与居中弹窗，支持弹窗内连续导航；Windows 支持 F11 全屏及退出后的窗口状态恢复。

## 稳定性改进

- 修复 Android 数据库升级、筛选设置保存、统计弹窗跳转及页面关闭后的异步刷新问题。
- 改进登录过期提示、同步重试与笔记冲突处理，修复 Gitee / R2 链接被错误套用 GitHub 代理的问题。
- 发布前通过 135 项自动化测试，静态分析无警告。
